# BARドリンク学習アプリ（個人用PWA）

店のドリンクメニュー（作り方・味わい・香り・略称・価格）を覚えるための個人用アプリです。
HTML / CSS / JavaScript だけで動きます（ビルド不要）。データは Googleスプレッドシートで管理します。

```
index.html          画面の土台
config.js           CSVの公開URLを書く設定ファイル
css/style.css       デザイン
js/                 アプリ本体（app.js が入口、views/ が各画面）
data/menu.csv       初期データ（menu.pdf から作成）
images/             ドリンクの写真（WebP）
icons/              アプリのアイコン
manifest.json, sw.js  PWA（ホーム画面追加・オフライン）
scripts/convert_images.py  写真をWebPに一括変換するスクリプト
```

---

## 1. パソコンで動作確認する

`index.html` をダブルクリックで開いても動きません（ブラウザがCSVの読み込みを止めるため）。
簡易サーバーを起動して開きます。

```bash
cd ~/Desktop/アプリ/Bar_menu
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。
Chrome なら、開発者ツール（⌥⌘I）のデバイスツールバー（⇧⌘M）で iPhone の画面サイズにして確認できます。
止めるときはターミナルで `Ctrl + C` を押します。

**同じWi-Fiのスマホで確認する場合**：`python3 -m http.server 8000 --bind 0.0.0.0` で起動し、
スマホで `http://（MacのIPアドレス）:8000` を開きます（IPアドレスは「システム設定 → Wi-Fi → 詳細」で確認）。
※ ホーム画面追加とオフライン機能は https が必要なので、GitHub Pages で公開してから確認してください。

## 2. スプレッドシートに取り込んでCSVで公開する

1. [Googleスプレッドシート](https://sheets.google.com) で空白のシートを新規作成
2. 「ファイル → インポート → アップロード」で `data/menu.csv` を選択
   - インポート場所：「現在のシートを置換する」
   - 区切り文字：「自動的に検出する」
   - 「テキストを数値、日付、数式に変換する」は**オフ**にする（価格の「ASK」や「1/2」などを崩さないため）
3. 「ファイル → 共有 → ウェブに公開」を開く
   - 「リンク」タブで、対象を **シート名**、形式を **カンマ区切り形式（.csv）** にして「公開」
   - 表示された URL（`https://docs.google.com/spreadsheets/d/e/…/pub?gid=0&single=true&output=csv`）をコピー
4. `config.js` の `CSV_URL` に貼り付けます

   ```js
   window.APP_CONFIG = {
     CSV_URL: "https://docs.google.com/spreadsheets/d/e/xxxxxxxx/pub?gid=0&single=true&output=csv",
   };
   ```

5. 変更をGitHubに反映すると、アプリはスプレッドシートを読むようになります

**編集するときの注意**
- 1行目の列名（`id`, `category` …）は変えないでください。列の並び順は変えても大丈夫です
- `ingredients`（材料）と `steps`（作り方）は、セル内で改行して1行ずつ書きます（Macは ⌘+Enter、スマホは改行キー）
- `serve` は `R,ST,S` のように書くと「ロック / ストレート / ソーダ割り」と表示されます
- `price` は数字だけ（`800`）か `ASK` と書きます
- 店のレシピで確認したら `verified` を `TRUE` にすると「未確認」バッジが消えます
- `sort` は並び順です。10刻みにしてあるので、間に追加するときは `15` などにします
- Googleの公開CSVは反映まで数分かかることがあります。アプリは起動時に自動で再取得し、右上の更新ボタン（↻）でも再取得できます
- 一度読み込んだデータはスマホに保存されるので、電波がなくても使えます

## 3. 写真を追加する

### A. Googleドライブで管理する（手軽）

1. Googleドライブに写真用のフォルダを作り、写真をアップロード
   （縦長・グラスが中央の写真がおすすめ。アプリでは4:5に切り抜いて表示します）
2. フォルダを右クリック →「共有」→ 一般的なアクセスを **「リンクを知っている全員」**（閲覧者）にする
   （フォルダごと設定すれば、中の写真すべてに適用されます）
3. 写真を右クリック →「共有」→「リンクをコピー」
4. スプレッドシートの `image` 列に、そのリンクをそのまま貼り付けます
   （`https://drive.google.com/file/d/…/view?usp=sharing` の形。アプリが自動で画像用のURLに変換します）

- 共有が「制限付き」のままだと表示されません（イラストが表示されます）
- 写真のアカウントはスプレッドシートやGitHubと別でも構いません
- 一度表示した写真はスマホに保存され、オフラインでも表示されます

### B. GitHub の images/ に置く（表示が速く確実）

1. 写真のファイル名を、そのドリンクの `id` と同じにします（例：`gin-tonic.jpg`、`laphroaig-10.heic`）
2. 写真をまとめて1つのフォルダに入れ、変換スクリプトを実行します

   ```bash
   pip3 install pillow           # 初回のみ
   pip3 install pillow-heif      # iPhoneのHEIC写真がある場合のみ
   python3 scripts/convert_images.py ~/Desktop/元の写真フォルダ
   ```

   → 縦横比4:5に中央で切り抜き、横800pxのWebPにして `images/` に保存します
   （横800px未満の写真は拡大しません。切り抜きたくない場合は `--no-crop` を付けます）

3. スプレッドシートの `image` 列にファイル名を書きます（例：`gin-tonic.webp`）
   - `https://…` で始まるURLを書くと、ネット上の画像をそのまま使います
   - 空欄のドリンクには、カテゴリ別のイラストが表示されます
4. `images/` をGitHubにアップロードします。表示した画像は自動で保存され、オフラインでも表示されます

## 4. GitHub Pages で公開する

1. [GitHub](https://github.com) にログインし、右上の「+ → New repository」でリポジトリを作成
   （例：`bar-menu`。個人用なら Private でも Pages は使えますが、無料プランでは **Public** が必要です。
   Public にする場合、メニュー内容や価格は誰でも見られる状態になる点に注意してください）
2. このフォルダの中身をアップロードします
   - ブラウザの場合：リポジトリ画面の「Add file → Upload files」に、フォルダの中身をすべてドラッグ
   - ターミナルの場合：
     ```bash
     cd ~/Desktop/アプリ/Bar_menu
     git init && git add . && git commit -m "first commit"
     git branch -M main
     git remote add origin https://github.com/ユーザー名/bar-menu.git
     git push -u origin main
     ```
   - `menu.pdf` を公開したくない場合は、アップロードから外してください
3. リポジトリの「Settings → Pages」で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分後、`https://ユーザー名.github.io/bar-menu/` で開けるようになります

**アプリ本体（js / css など）を更新したとき**は、`sw.js` 先頭の `VERSION`（例：`"v1"` → `"v2"`）を変えてからアップロードしてください。
スマホ側では、アプリを1回開き直すと新しい版に切り替わります。
（メニューデータや写真の追加だけなら、VERSION を変える必要はありません）

他の静的ホスティング（Netlify、Cloudflare Pages など）にも、このフォルダをそのままアップロードすれば動きます。

## 5. スマホのホーム画面に追加する

**iPhone（Safari）**
1. Safari で公開URLを開く
2. 下の共有ボタン（□↑）→「ホーム画面に追加」→「追加」

**Android（Chrome）**
1. Chrome で公開URLを開く
2. 右上の「⋮」→「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面から開くとアプリのように全画面で動きます。一度開いておけば、オフラインでも閲覧・学習できます。

---

## 6. 進捗のバックアップ（機種変更のとき）

学習の進捗（覚えた・苦手リスト・クイズ成績）はスマホのブラウザ内に保存されています。

1. 古いスマホで「進捗 → バックアップ → 書き出し」→ ファイルを保存（iPhoneは「ファイルに保存」、AirDrop、メールなど）
2. 新しいスマホでアプリを開き、「進捗 → バックアップ → 読み込み」でそのファイルを選択

※ iPhone では、Safari で開いた場合とホーム画面から開いた場合で、保存場所が別になります。
　 ホーム画面のアプリを使い始める前にSafariで学習していた場合は、同じ手順で移してください。

## 使い方メモ

- **メニュー**：ジャンル → ドリンク一覧 → 詳細。詳細では左右スワイプで前後のドリンクに移動します。右上の🔍で商品名・略称・材料を横断検索できます
- **カード**：カテゴリと出題範囲（すべて／未習得のみ／苦手のみ）を選んでスタート。下のテキスト部分をタップすると裏返ります。右スワイプ＝覚えた、左スワイプ＝まだ
- **クイズ**：10問の4択。間違えたドリンクは苦手リストに入り、3回連続で正解すると外れます
- **進捗**：カテゴリ別の覚えた率、苦手リストからの復習、クイズ成績、バックアップ
